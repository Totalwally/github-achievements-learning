# Achievements and Pull Shark

Pull Shark is a GitHub profile achievement related to having pull requests merged. GitHub controls how achievements are awarded, and its eligibility criteria can change.

This repository demonstrates pull-request automation as a learning exercise. The script does not guarantee Pull Shark, any other achievement, or a particular amount of profile credit. A merged pull request created by the script may not meet GitHub's current eligibility requirements. Check [GitHub's achievement reference](https://docs.github.com/account-and-profile/reference/profile-achievements) for current details.

Use the script only in a repository where you have permission, and prefer a small iteration count. A large number of automated pull requests can create noise for collaborators and may be restricted by repository settings or GitHub.
